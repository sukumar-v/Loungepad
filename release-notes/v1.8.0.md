The controller on admin prompts and the sign-in screen, Steam games left to Steam, and a smoother
pointer everywhere.

## New

- **The controller on admin prompts and the sign-in screen (beta).** Turn it on under Settings →
  Advanced, separately for UAC prompts and for the lock and sign-in screens. The left stick moves
  the pointer, A clicks, and the Loungepad keyboard types your PIN or password. It runs as a
  separate signed Windows service, so Windows asks for administrator approval once when you turn
  it on, and it keeps working while Loungepad is closed. When Loungepad updates, it offers to
  update the service too. Turning both switches off keeps it installed; you can uninstall it from
  the same place.
- **Steam drives its own games.** In Big Picture, and in any game Steam starts, Loungepad leaves
  the controller to Steam: the menu combo still works, but the stick no longer moves the mouse and
  A no longer clicks on top of Steam's own controls. Switch it off under Settings → Controller →
  Windows and Steam.
- **What's new, and when to restart.** After an update, Loungepad shows these notes the first time
  it opens. When an update finishes downloading in the background, it asks whether to restart now
  or install it the next time Loungepad starts.
- **A smaller on-screen keyboard.** Its size now goes down to 30%, for handhelds and small screens,
  and with word suggestions off the empty suggestion bar is gone.
- **Join the Discord** from Settings → General.

## Fixed

- **The pointer moves the same everywhere.** The stick uses one speed curve on the desktop, on
  admin prompts and on the sign-in screen, and no longer moves faster on a diagonal. Each move
  lands on the exact pixel it aims for, which removes a wobble.
- **A DualSense that is paired and plugged in is one controller.** It was read twice, over the
  cable and over Bluetooth, and the pointer jittered.
- **The on-screen keyboard is the right size at any display scaling.** At 150% and up it came out
  too big, and the size setting did nothing.
- **A held button shortcut fires once.** Show desktop on LB + RB flipped between the desktop and
  your windows for as long as the buttons were held.
- **Power Wheel shortcuts open in front.** The Volume Mixer, Display Settings and other shortcuts
  could open behind Loungepad.
- **Task Manager is off the Power Wheel's shortcuts.** It runs as administrator, so the controller
  couldn't use it without the input service, which made the shortcut look broken.
- **Settings follows the mouse.** Hovering a category no longer lights up an option on the right
  for a moment, and A presses whatever the pointer is on.
- **Settings stays where you scroll it.** It jumped back to the highlighted option every few
  seconds.

## Known issues

- **On the sign-in screen, an Xbox controller works the way Windows does.** Press the Xbox button
  to bring up the PIN field, then A on it for Windows' keyboard. Loungepad's pointer and keyboard
  work there with a PlayStation controller.
- **With only a Steam sign-in, a private profile's achievements can't be read.** Set Game details
  to Public in Steam's privacy settings, or add your own Steam Web API key under Settings → Library.
- **Epic achievements are failing:** Epic's servers currently answer with a security check that
  Loungepad can't pass.

## Download and install

1. Under **Assets** below, download **Loungepad.exe**. That one file is the whole app.
2. Put it anywhere you like, such as your Desktop, and double-click it.
3. If Windows says it protected your PC, click **More info**, then **Run anyway**.

Already using Loungepad? It updates itself, so there is nothing to download. You can ignore the
other files: Loungepad fetches the input service itself when you turn it on, and the
`-win-x64.zip` is only for copies on version 1.6.3 or older.
