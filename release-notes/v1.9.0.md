Community themes and extensions, installed from the sofa, and the first extension: HowLongToBeat.

## New

- **Settings → Add-ons.** Themes and extensions made by other people, found, installed, updated and
  removed from inside Loungepad. Two tabs, Themes and Extensions, each showing what is installed
  and what the community repository has; A on one opens its page, Y is the short menu. A theme or
  extension that is not in the repository installs from a zip or a folder on your PC.
- **Extensions.** Small scripts that add something to Loungepad. The first kind is a metadata
  source: it fetches facts about each game and Loungepad shows them on the game's page, and a
  theme can draw them too. An extension runs in a sandbox of its own: it can reach only the hosts
  its page lists, and it cannot read your settings, your files or your accounts, start anything,
  or draw on the screen. Each one says what it reaches before it is installed. Writing one is a
  manifest and a JavaScript module; see docs/ADDONS.md.
- **HowLongToBeat.** How long each game takes to beat -- main story, with extras, completionist --
  from howlongtobeat.com, under the facts on every game's page. Install it under Settings →
  Add-ons → Extensions.
- **The add-ons repository.** [github.com/sukumar-v/loungepad-addons](https://github.com/sukumar-v/loungepad-addons)
  holds every community theme and extension. A pull request adds one or updates it; a merge is
  the release, and every Loungepad sees the new version the next time it looks.

## Changed

- **Settings → Appearance** keeps the theme picker and each theme's options; installing and
  removing themes has moved to Add-ons.

**Full Changelog**: https://github.com/sukumar-v/Loungepad/compare/v1.8.0...v1.9.0

## Download and install

1. Under **Assets** below, download **Loungepad.exe**. That one file is the whole app.
2. Put it anywhere you like, such as your Desktop, and double-click it.
3. If Windows says it protected your PC, click **More info**, then **Run anyway**.

Already using Loungepad? It updates itself, so there is nothing to download. You can ignore the
other files: Loungepad fetches the input service itself when you turn it on, and the
`-win-x64.zip` is only for copies on version 1.6.3 or older.
