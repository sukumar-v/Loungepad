The Power Wheel and Loungepad get a button each, the keyboard comes up when you click a text field,
and your library is kept safe through every update.

## New

- **The Power Wheel and Loungepad have a button each.** Settings → Controller used to have one
  menu combo for both: tap it for the Power Wheel, hold it to show or hide Loungepad. Now the
  Power Wheel button and the Loungepad button are two settings, each any button or combination
  you like, with its own gesture: a tap, a hold or a double tap. Out of the box nothing changes:
  tap the Xbox button for the Power Wheel, hold it for Loungepad. Your old combo carries over.
- **Show only.** Set "Loungepad button does" to Show only and the button only ever brings
  Loungepad forward, so a stray press can never hide it and drop you on the desktop. Minimize
  Loungepad on the library's hint bar still hides it.
- **Record any button setting.** The Power Wheel and Loungepad buttons, the keyboard button, the
  left and right click buttons, the speed boost button and the screenshot combo all work the same
  way now: press A on the row, choose Record a button…, and press what you want. Any of them can
  be unset, and an unset row says what no longer has a button. Settings warns you when two of them
  share a button, or when Windows or Steam answer the same press.
- **The keyboard comes up when you click a text field.** Click a text field with the controller
  outside Loungepad (in a browser, in Notepad, in a sign-in box) and the Loungepad keyboard opens,
  as on a phone. A real mouse never opens it. Turn it off under Settings → Keyboard → Open on text
  fields, or from the gear on the keyboard.
- **Paste from the keyboard.** Before you type anything, the middle suggestion offers what you
  copied: a preview of the text, or a picture or files. Pick it and it pastes, just as Ctrl+V
  would. Copy something while the keyboard is up and the offer follows. Deleting text or moving
  the cursor keeps the offer there. It needs word suggestions turned on.
- **Close the keyboard with the mouse.** The keyboard's bar has an X now, for when you come back
  to the desktop with only a mouse and keyboard and find it still up. The bar and the X shrink
  with the keys at small sizes. Thanks to @asakahn.
- **Start minimized at login.** Turn on Settings → General → Start minimized at login and
  Loungepad starts in the system tray when Windows starts, ready for the controller, instead of
  opening full screen. Thanks to @asakahn.
- **Steam family games.** If you are in a Steam family, the games your family shares with you join
  the library beside the games you own, greyed out until they are installed and installable from
  the library like your own. Settings counts them separately. Like the rest of your Steam
  library, they need the Steam sign-in or your own Web API key under Settings → Library.

## Fixed

- **Your library survives an update.** Closing Loungepad to update could cut a save off halfway.
  The next start then found a library it could not read, started empty and saved over it, and the
  games you had added by hand, your playtime and your collections were gone. Saves are now written
  whole or not at all, every start keeps a backup copy, and a library that will not load is set
  aside and the backup loaded instead: it is never saved over. This protects every update from
  this one on; the update into 1.12.0 is still made by the version you have now.
- **A held button no longer opens the Power Wheel by accident.** A press held past the hold time
  is never counted as a tap now, so holding the Xbox button with no Loungepad button set does
  nothing when you let go.
- **The D-pad presses once in games with the joystick mouse off.** With the joystick mouse turned
  off, the D-pad also sent arrow keys outside Loungepad, so some games moved two steps for every
  press. Thanks to @asakahn.
- **No stray right-click when the input service starts.** The input service could open the
  desktop's right-click menu as it started, by letting go of mouse buttons nobody was holding. It
  now lets go only of buttons that are actually down. If you use the input service, Loungepad
  offers to update it the first time this version starts. Thanks to @asakahn.

## Download and install

1. Under **Assets** below, download **Loungepad.exe**. That one file is the whole app.
2. Put it anywhere you like, such as your Desktop, and double-click it.
3. If Windows says it protected your PC, click **More info**, then **Run anyway**.

Already using Loungepad? It updates itself, so there is nothing to download. You can ignore the
other files: Loungepad fetches the input service itself when you turn it on, and the
`-win-x64.zip` is only for copies on version 1.6.3 or older.
